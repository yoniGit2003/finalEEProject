# docs/: project documents

This folder is for project-level material: the proposal and, later, the report, thesis text and its figures.
Nothing else for now. Documentation of the data and the pipeline lives in [`../pipeline/docs/`](../pipeline/docs/)
(start with `DATA_GUIDE.md`); research code and results live in [`../research/`](../research/).

The two project reports are here: `research_log.pdf` (the research at the level of ideas: what is implemented,
where we stand, what comes next; source `research_log.tex`, updated by `/tidy`, built with
`python pipeline/tools/build_research_log.py`) and `pipeline_log.pdf` (technical report of the data layer; no
LaTeX source in the repository).

Other contents: `proposal.md` / `proposal.docx` (project proposal, revised after the guide's comments), `media/` (its
figure), `sindy_intro_report_2026-03.pdf` (our report "Introduction to SINDy", March 2026; formerly `Rain_project.pdf`), `organization/` (audit, plan and report of the 2026-10-07 reorganization; the rules themselves: `../ORGANIZATION.md`).
